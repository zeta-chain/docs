> **ZETA moves to Solana on Dec 9, 2026**, as a native token, 1:1 under the same
> ticker. The ZetaChain Layer 1 described on this page halts at block height
> 20,755,000, expected around Dec 9, 2026, and is not restarted. ZetaScan remains
> available, and an archive node with read-only RPC is provided through Oct 31,
> 2027. See the [whitepaper](https://www.zetachain.com/whitepaper.pdf) and the
> [ZetaHub migration portal](https://hub.zetachain.com/migrate).

ZetaChain builds [ZetaLabs](https://www.zetachain.com/zetalabs), a private AI
chat with leading AI models, live market data and a private memory you control.
These docs cover the ZetaChain network, the Proof of Stake Layer 1 that ZETA
runs on until the migration to Solana.

The ZetaChain Layer 1 is a Proof of Stake blockchain. It is built on the
[Cosmos SDK](https://docs.cosmos.network/) and uses the
[CometBFT](https://docs.cometbft.com/) consensus engine, with full EVM
compatibility provided by [Cosmos EVM](https://evm.cosmos.network/).

The chain has ~5 second blocks with instant finality, an EIP-1559 fee market,
and a native staking and gas token (ZETA). Validators secure the network
through delegated proof of stake.
